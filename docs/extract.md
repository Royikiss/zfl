# extract (万能解压与一键压缩工具)

`extract` 是 ZFL 内置的高性能命令行解压与压缩一体化工具。设计遵循极简交互哲学：**不传格式参数默认自适应解压；传入格式参数直接一键压缩**，并支持使用 `-p` 设置加密密码或解密受保护文件。

---

## 📖 使用方法与示例

### 1. 默认解压模式 (无需任何选项)
直接传入压缩包文件名，自动识别格式并解压，内置重名碰撞防护与防解压炸弹保护：
```bash
extract project.tar.gz               # 自动解压 tar.gz
x release.zip docs.7z                # 快捷别名，同时解压 zip 与 7z
extract -p 123456 secret.zip        # 解压带密码的压缩包
```

### 2. 一键压缩与密码加密模式
传入格式选项（如 `--zip`, `--tar.gz`, `--7z`）触发压缩，可使用 `-p <密码>` 加密：
```bash
extract --zip my_folder/                    # 自动压缩为 my_folder.zip
extract --zip -p 123456 confidential/      # 加密压缩为 zip
extract --7z -p mypass -o secret assets/   # 指定输出名为 secret.7z 并加密
```

---

## 🛡️ 重名碰撞与防“解压炸弹”保护 (Collision & Bomb Defense)

1. **解压重名碰撞保护**：提取的目标如果与当前工作目录中的项同名，自动释放至唯一隔离文件夹（如 `folder_1/`），**绝不覆盖当前已有文件**。
2. **多文件平铺防炸弹**：自动检测包内散落的多项文件，若无顶层文件夹，自动新建同名专属文件夹解压。
3. **压缩同名覆盖保护**：生成的目标文件名若在当前目录已存在，自动递增重命名为 `archive_1.zip`，防止冲掉旧压缩包。

## ⚙️ 格式参数对照表

| 选项参数 | 输出文件后缀 | 说明 |
| :--- | :--- | :--- |
| `-p <密码>` | N/A | 指定加密或解密密码 |
| `-o <包名>` | N/A | 指定输出压缩包名称 |
| `--zip` | `.zip` | 通用 zip 压缩格式 (支持加密) |
| `--tar.gz` / `--tgz` | `.tar.gz` / `.tgz` | tar 打包 + gzip 压缩 |
| `--tar.bz2` / `--tbz2` | `.tar.bz2` / `.tbz2` | tar 打包 + bzip2 压缩 |
| `--tar.xz` / `--txz` | `.tar.xz` / `.txz` | tar 打包 + xz 极高压缩率 |
| `--tar.zst` / `--tzst` | `.tar.zst` / `.tzst` | tar 打包 + zstd 极速高压缩率 |
| `--7z` | `.7z` | 7-Zip 高压缩率归档 (支持加密) |
| `--rar` | `.rar` | RAR 归档格式 (支持加密) |
| `--tar` | `.tar` | 未压缩的 tar 打包归档 |

---

## 💡 Zsh Tab 自动补全

在终端输入 `extract -` 或 `x -` 并按 **Tab** 键，系统自动提示参数菜单与说明：

```bash
-p         -- 指定压缩/解压密码
-o         -- 指定输出文件名
--zip      -- 一键压缩为 .zip 格式
--7z       -- 一键压缩为 7-Zip (.7z)
--tar.gz   -- 一键打包压缩为 .tar.gz
```
