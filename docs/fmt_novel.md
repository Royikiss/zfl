# fmt_novel

`fmt_novel` 是一个封装在 ZFL 框架下的自定义函数，专门用于处理小说、文章章节的行间距与每行首尾空格/空行排版，并深度规范中文字符符号及标点格式。

---

## 🌟 功能特点

1. **行格式化（处理每一行）**：逐行清除全角/半角空格、Tab、回车符等无用空白字符。
2. **标点符号自动规范**：
   - **英文直角引号/直引号转换**：自动识别配对的英文半角直引号 `""` 和 `''` 并转换为符合中文排版规范的弯引号 `“ ”` 与 `‘ ’`（同时智能保留英文单词内部的省字号，如 `it's`, `don't`）。
   - **特殊括号转换**：将 `【` `「` `『` `❲` 统一替换为中文前双引号 `“`，将 `】` `」` `』` `❳` 统一替换为中文后双引号 `”`。
3. **Markdown 加粗/斜体语法清洗**：
   - 自动识别并剥离 Markdown 加粗 (`**xxx**`) 及斜体 (`*xxx*`) 的外侧星号，将其统一规范为标准中文引号 `“xxx”`（若内部本身包含 `“ ”` / `‘ ’` / `《 》` / `" "` / `' '`，则自动清理外侧残留星号，防止出现 `*“xxx”*` 类型的非法组合格式）。
4. **全套出版级标点规范**：
   - **省略号与破折号**：自动将 `...` / `。。。` 统一规范为 `……`，将英文 `--` 或中文单短横线规范为 `——`（保留 Markdown 原有 `---` 分割线）。
   - **半角转全角标点**：自动将中文语境下的英文半角标点 `, : ; ! ? .` 转换为中文全角 `，：；！？。`（避开英文文件名如 `.docx` 及数字小数）。
   - **标点与空格清理**：清除标点符号与文字之间多余的空格（如 `你好 ，` ➔ `你好，`）。
   - **情绪标点收敛**：自动收敛连续过多的感叹号/问号（如 `！！！` ➔ `！`，`！?` ➔ `？！`）。
   - **书名号转换**：自动将 `<<书名>>` 转换为 `《书名》`。
5. **段间空行处理（处理行间距）**：
   - **默认模式**：彻底移除段落与段落之间的空行，紧凑排列。
   - **`-k` / `--keep-one` 模式**：保留单空行分隔段落。
6. **严禁删文**：严格保留文章所有正文文本与段落顺序，不删改任何非空白文字。
7. **剪切板输出**：格式化结果自动复制到系统剪切板（支持 `wl-copy`, `xclip`, `xsel`, `pbcopy`）。
8. **多输入模式**：支持指定文件路径、管道标准输入 (`stdin`) 以及直接对系统剪切板现有的文本进行就地排版。

---

## 📖 用法说明

```bash
fmt_novel [-k|--keep-one] [文件路径|-h]
```

### 参数与示例

- **深度排版处理指定文件（消除了斜体星号包裹引号问题）**：
  ```bash
  fmt_novel 字里行间/output/novel/chapters/19.md
  ```

- **保留单空行模式**：
  ```bash
  fmt_novel -k 19.md
  ```

- **处理管道输入的文本**：
  ```bash
  cat novel.md | fmt_novel
  ```

- **对剪切板文本就地格式化（无参数时自动读写剪切板）**：
  ```bash
  fmt_novel
  ```

- **查看帮助**：
  ```bash
  fmt_novel -h
  ```
